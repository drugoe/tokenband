# TokenBand 0.6.6 — experimental

Version **0.6.6**, revision **20261120.1** · [MIT](../../LICENSE)

TokenBand is a workflow skill for AI agents: a shared project task list, persistent task chats, configurable execution roles and independent review before manager acceptance. Full execution requires a compatible host integration; instruction loading alone does not establish support for the complete lifecycle.

The installation package is unchanged by the repository presentation update. Model usage and API access are configured separately. This is an experimental version.

## Русский

TokenBand организует работу ИИ-агентов: единый список задач проекта, постоянные чаты задач, настраиваемые роли исполнения и независимая проверка перед приёмкой менеджером. Для полного процесса нужна совместимая интеграция с приложением; загрузка инструкций сама по себе её не подтверждает.
