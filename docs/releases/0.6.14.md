# TokenBand 0.6.14

Experimental release, 26 November 2026.

Task chat titles show the state recorded in the project TODO. Use 🟡 for queued work, ⚙️ once substantive work starts, and ✅ after the manager records acceptance. Explicitly reopened tasks return to 🟡 while awaiting dispatch. Title updates preserve the chat ID, task number and description.

В заголовке чата 🟡 означает очередь, ⚙️ — подтверждённое начало работы, а ✅ — приёмку результата в TODO. Переоткрытая задача получает 🟡, пока ждёт запуска. Номер, описание и сам чат сохраняются.
