# TokenBand 0.6.16

Experimental release · 27 November 2026 · revision 20261127.2.

- Task titles use ❌ for explicit cancellation by a human and 🚫 for authorized cancellation when verified circumstances make the task unnecessary. Reopening preserves the recorded cancellation history.
- At an authorized start or resume, an admitted task chat records the actual start in TODO and sets its own ⚙️. An explicitly handed-over chat keeps its ID and history when the manager adds it to the project queue and sets its first managed title.
- Task chats can send a short human-wait notice under a standing grant. Manager titles show task numbers for subordinate human waits. Manager role icons are 👑 for the chief, 🧑‍💼 for other active managers, and 👤 for former managers.

Экспериментальный выпуск · 27 ноября 2026 года · ревизия 20261127.2.

- ❌ отмечает явную отмену человеком, 🚫 — согласованную отмену, когда по подтверждённой причине задача больше не нужна. При повторном открытии запись об отмене остаётся в истории.
- При разрешённом старте или возобновлении чат задачи с допуском к записи фиксирует фактический старт в TODO и сам ставит ⚙️. При явной передаче существующего чата менеджер сохраняет его ID и историю, привязывает его к задаче и задаёт первый заголовок.
- Чат может сообщить менеджеру об ожидании ответа по заранее выданному разрешению. Заголовок менеджера показывает номера ожидающих задач. 👑 обозначает главного менеджера, 🧑‍💼 — действующего менеджера своего участка, 👤 — бывшего менеджера.
