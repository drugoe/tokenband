# Resume checkpoint

Store in existing plan/evidence; link from the sole authoritative TODO. This checkpoint is context, not a parallel status queue. Resolve current ownership/status from TODO at restart, then reconcile receipts before taking action.

- Binding: canonical project folder/root and, when different, the actual task or worktree work directory; TODO item; current owner/write-set; same assignment/invocation and route; allocated task chat if any, its sprint and stage identifiers/prefix when applicable, same exact chat/session/relevant turn only for a persistent route; integration owner; accepted dependency evidence.
- Snapshot: accepted output and current input identity using the project-chosen mechanism, including relevant dirty/untracked content when VCS applies or native object IDs/revisions and accessible content otherwise; relevant freshness/drift check and evidence paths. Refresh affected scope if stale.
- Decisions: accepted human decisions/consent and operative restrictions; material assumptions/unknowns; rejected alternatives only when needed to avoid repetition.
- Review: exact reviewed bytes, required stages and received conclusions, open finding IDs/dispositions/recheck evidence; completed execution awaiting acceptance stays unaccepted.
- Operations: original invocation/continuation and receipt IDs, actual last observed state/time, first unknown acknowledgement/result time, confirmed progress, partial artifacts, ownership/cleanup/isolation evidence and late results.
- Alternative: linked read-only assignment identity, inputs/snapshot, authorization, persisted dispatch intent and returned identity/state, if any. Reconcile ambiguous intent/outcome after restart; never blindly dispatch it again. Preserve the original unknown receipt and write ownership.
- Next safe action: one concrete unfinished step, its prerequisite/stop condition and evidence to inspect. Do not restart paused work, allocate another chat or replay an uncertain operation.

Follow [operations](../references/operations.md) for the limited 15-minute fresh read-only uncertainty continuation, whole-chain bounds, late-result reconciliation and shared-integration boundary. Expiry does not mean termination. Known-running confirmed progress follows normal observation. A matching snapshot alone does not exclude future original writes; preserve isolation until the required boundary is established.
